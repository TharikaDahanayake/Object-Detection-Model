# Everyday is a Learning Day !

## Multi-Model Real-Time Object Detection System

### Overview
This project is an enhanced object detection system built using Python, OpenCV, and YOLOv8, capable of detecting 100+ object types in real time. By running 5 different AI models simultaneously, the system achieves superior accuracy and robustness.

It includes specialized detection for:

- Spectacles
- Books
- Chess Pieces (12 classes)
- General-purpose objects
- MobileNet SSD general objects

### Key Features

#### Multi-Model Detection (5 Models)
- MobileNet SSD – 20+ common objects
- YOLOv8 Books – Custom trained
- YOLOv8 Spectacles – High accuracy
- YOLOv8 General Objects – 80 COCO classes
- YOLOv8 Chess Pieces – 12 custom classes

#### Performance
- Smart deduplication algorithm
- Color-coded bounding boxes
- Clean console output

### Technologies Used

Python 3.8+
OpenCV
YOLOv8 (Ultralytics)

ML Training
